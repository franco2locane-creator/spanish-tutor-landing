# QR code

Generated by `qr/generate-qr.js` from the final landing page URL.

## Generate

```
npm install
npm run generate-qr -- https://your-real-url.example/
```

Outputs `qr-code.svg` and `qr-code.png` into this folder.

## Printing

- **Use the SVG on the flyer.** It's vector, so it scales cleanly to
  any print size.
- **Never scale up the PNG.** It's fixed at 2000px, exported only for
  on-screen previews and mockups — enlarging it will blur and can
  break scanning.
- **Print at 2.5cm minimum** on a side. Below that, most phone
  cameras struggle to resolve the modules, especially at a distance
  or on lower-quality print stock.
- Error correction is set to level H (highest), so the code should
  still scan even if the print smudges slightly or a logo is placed
  in the centre later. Don't recolour the code or drop the quiet zone
  below 4 modules — low contrast is the most common reason a printed
  QR code fails to scan.
